## 6. 사용방법 (패키지 표기)
1. 깨끗하게 세안 후 토너를 이용하여 피부결을 정돈합니다.
2. 제품을 개봉하여 마스크를 얼굴에 고르게 붙여 밀착합니다.
3. 10~20분 뒤 마스크를 떼어냅니다.
4. 남아있는 에센스를 가볍게 두드려 흡수시킵니다.

## 7. 사용할 때의 주의사항 (패키지 표기)
1. 화장품 사용 시 또는 사용 후 직사광선에 의하여 사용부위가 붉은 반점, 부어오름 또는 가려움증 등의 이상 증상이나 부작용이 있는 경우에는 전문의 등과 상담할 것
2. 상처가 있는 부위 등에는 사용을 자제할 것
3. 보관 및 취급 시의 주의사항
   - 가) 어린이의 손이 닿지 않는 곳에 보관할 것
   - 나) 직사광선을 피해서 보관할 것
4. 눈 주위를 피하여 사용할 것

- 붙이는 반창고나 습포에 자극이 약한 분은 사용을 주의해 줄 것
- 개봉 후에는 제품이 건조되므로 바로 사용하시고 사용한 마스크는 재사용을 삼가해 줄 것

## 9. ⚠️ 등록 전 확인 필요 사항

1. **인삼 vs 홍삼 표기 불일치**
   - 패키지 전성분은 "락토바실러스/**홍삼**발효여과물"입니다.
   - 제조증명서와 원료사 MSDS(Natural SW)는 "Lactobacillus/**Panax Ginseng Root** Ferment Filtrate", 즉 인삼뿌리발효여과물입니다.
   - 원료사에 정확한 표준 한글명을 확인하세요. 패키지가 틀렸다면 다음 인쇄분부터 수정해야 합니다.
   - 확인 전까지 상세페이지에서는 "인삼 발효 성분"으로 표현하는 것을 권장합니다. 진세노사이드(BTGin 원료)는 홍삼 유래로 표현해도 됩니다. MSDS상 홍삼 특유의 향이 기재되어 있습니다.
2. **PDRN·마데카소사이드·펩타이드는 미량입니다.**
   - 소듐디엔에이 0.000002%, 마데카소사이드 0.0003%, 펩타이드 0.0000075~0.00002%입니다.
   - 패키지 앞면에 "PDRN & MADECASSOSIDE"가 강조되어 있으므로, 상세페이지에서 이 성분들을 메인 헤드라인으로 쓰지 마세요.
   - 강조할 때는 "함유" 표현과 함량 표기를 함께 사용하세요.
3. **TENCEL™ 상표 (Lenzing AG)**
   - 시트 공급사에 렌징 인증서(라이선스)를 확인하세요.
   - 확인 전에는 상세페이지 문구에 "텐셀 시트"를 크게 쓰지 말고 "프리미엄 시트"로 대체할 수 있습니다.
4. **제조증명서 CAS 번호 오기 (B2B 제출 시 수정)**

5. **pH 표기**
   - 보고서는 6.7, 시험성적서 실측은 6.5입니다. 둘 다 규격 6.7±0.5 이내입니다.
   - 상세페이지에 pH를 쓴다면 "pH 6.5~6.7"로 표기하세요.
