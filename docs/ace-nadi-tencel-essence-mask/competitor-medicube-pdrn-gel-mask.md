## 3. 핵심 전략 분석

### ① 모든 주장을 숫자로 증명한다 (가장 큰 특징)
- 확인된 효능 수치는 **20개 이상**이며 모두 "인체적용시험 보고서 발췌"입니다.
- 시점을 분리해서 수치를 많이 확보했습니다.
  - 즉시: 1회 사용 직후
  - 24시간
  - 2주
- 법적 안전장치로 쓰는 각주는 다음과 같습니다.
  - "개인 별 차이가 있을 수 있습니다"
  - "일시적 붉은기에 한함"
  - "눈에 보이는 모공으로, 일시적 효능에 한함"
  - "피부 탄력 증가로 인한 효과를 의미함"
  - "PDRN: 소듐디엔에이, 원료 특성에 한함"
- 측정기 화면(초음파, 주름 맵, 열화상)을 그대로 보여줘서 과학적인 인상을 줍니다.

### ② 눈으로 보이는 실험 데모
- 투명해지는 컬러체인지
- 무게 실험 (21g → 6g)
- 열화상 쿨링

이 세 가지가 "흡수가 된다"를 숫자 없이도 직관적으로 보여줍니다.

### ③ 원료에 이름을 붙인다
- "PDRN" 대신 **"Prism PDRN™"**, "콜라겐" 대신 **"310Da 저분자 콜라겐"**처럼 씁니다.
- 고유명사와 수치를 붙여서 원료의 격을 높입니다.

### ④ 가격 설계
- 장당 가격을 빨간 글씨로 가장 크게 표시합니다.
- 묶음이 커질수록 장당가가 내려갑니다 (4,300 → 4,084 → 3,800 → 3,500원).
- 24매 이상은 자사 다른 제품을 사은품으로 줘서 교차판매합니다.
- 상단 배치로 구매 결정을 먼저 유도합니다.

### ⑤ 라인업으로 객단가와 재구매를 높인다
- 사용 상황별(스페셜/데일리/나이트)로 제품을 나눕니다.
- 고객이 "다음에 살 제품"을 페이지 안에서 바로 고르게 만듭니다.

### ⑥ 디자인 톤
- 핑크·코랄 단색 계열
- 큰 세리프 숫자 (Step, 1mm, %)
- 굵은 고딕 한글 헤드라인 + 얇은 서브
- 1200px 폭, 섹션마다 여백이 넉넉합니다.

| 항목 | 메디큐브 PDRN 겔 마스크 | ACE NADI 텐셀 에센스 마스크 | 시사점 |
|---|---|---|---|
| 유형 | 하이드로겔, 1~3시간 | 텐셀 시트, 10~20분 | **직접 경쟁 아님.** ACE NADI는 메디큐브 "데일리" 라인과 같은 사용 상황 |
| 기능성 | 미백·주름개선 2중 | 미백·주름개선 2중 | 2중 기능성만으로는 **차별화 불가** |
| PDRN | **연어** PDRN (Prism PDRN™) | **유산균 발효** PDRN (FERMAGEN™ LAB-PDRN) | 비연어·발효 유래로 대비 가능 (함량 표현 주의) |

| 판매 장치 | 정품 배너, 연예인 추천, 묶음·사은품 | 미정 | 묶음 구성·장당가 표시는 바로 적용 가능 |

## 5. ACE NADI 상세페이지에 적용할 것

### 바로 적용 (추가 비용 없음)
1. **가격·구성 섹션을 상단에 배치합니다.**
   - 1매 / 10매 / 30매 구성, 장당 가격 크게 표시, 대용량에 사은품
2. **원료에 이름 붙이기**
   - "유산균 발효 PDRN (FERMAGEN™ LAB-PDRN)", "BTGin 홍삼 진세노사이드 (자체 원료)"처럼 씁니다.
   - 각주는 메디큐브 방식을 응용합니다: "*PDRN: 소듐디엔에이 함유, 원료 특성에 한함"
3. **각주로 안전장치 달기**
   - 모든 수치·주장 아래에 출처를 적습니다. 예: "*자사 시험성적서 기준", "*개인차가 있을 수 있습니다".
4. **눈에 보이는 데모를 직접 촬영합니다.**
   - **에센스 양 데모**: 파우치 1개를 유리컵에 짜서 23ml 보여주기 (메디큐브 물컵 GIF의 시트마스크 버전)
   - **무게 실험**: 사용 전후 시트 무게. 에센스가 피부로 이동한 양을 보여줍니다.
   - **텐셀 시트 데모**: 시트를 빛에 비춰 얇고 투명한 모습, 늘려도 찢어지지 않는 모습
   - 단, 무게 실험 결과를 "흡수량"으로 단정하지 말고 "사용 전후 시트 무게 변화"로 표현하세요.
5. **우리만 가진 섹션: 생산 영상 + 시험성적서**
   - 메디큐브에는 "어디서 어떻게 만드는지"가 없습니다.
   - "제조사가 직접 만든다"는 ACE NADI가 가장 강하게 내세울 수 있는 차별점입니다.

### 투자 필요 (효과 큼)
6. **인체적용시험 진행** (가장 시급)
   - 메디큐브 페이지의 설득력은 대부분 수치에서 나옵니다. ACE NADI도 아래 항목을 확보하면 같은 구조를 쓸 수 있습니다.

     | 측정 시점 | 항목 |
     |---|---|
     | 1회 사용 직후 | 피부 보습, 피부결, 피부 광채 |
     | 24시간 | 보습 지속 |
     | 2주 또는 4주 | 피부 밝기 (미백 기능성 연계), 눈가 주름 (주름개선 기능성 연계) |
     | 별도 | 피부 자극 테스트 ("피부자극 테스트 완료" 표기 가능) |

   - 시험기관(CRO) 견적으로 비용·기간을 확인하세요.
   - 메디큐브처럼 즉시·24시간·2주로 시점을 나누면 같은 시험에서 수치를 더 많이 얻습니다.
7. **측정 이미지 확보**: 시험기관에 측정기 Before/After 이미지 제공을 요청하세요 (주름, 밝기 등).

### 따라하지 말 것
- **"어려보이는", "동안"**: 노화 방지·연령 관련 표현은 심의 리스크가 있습니다. ACE NADI는 기능성 문구 범위 안에서 표현하세요.
- **"완벽", "압도적인", "극대화"** 같은 최상급 표현: 실증 자료가 없으면 부당 광고 소지가 있습니다.
- **"연예인 내돈내산 추천"**: 실제 근거(구매 증빙, 동의)가 없으면 쓰면 안 됩니다.
- **이미지·레이아웃 그대로 차용**: 저작권 경고가 있습니다. 구조만 참고하세요.
