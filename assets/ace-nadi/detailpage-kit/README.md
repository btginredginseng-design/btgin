# ACE NADI detail-page kit (for Claude.ai)

## Folders

| Folder | Contents |
|---|---|
| `logo/` | Transparent PNG logo parts, extracted from the pouch, in brand purple `#4A2470` and in white: `emblem` (the AN monogram), `wordmark` (ACE NADI + TENCEL ESSENCE MASK), `kname` (에이스 나디 텐셀 에센스 마스크) |
| `product/` | Pouch front and back cutouts (transparent PNG) plus the original photos. Use these as the product reference for AI image generation. |
| `production_stills/` | 1920×1080 color-graded stills from the real factory footage, one per GIF below |

## Production GIFs
The GIFs ship in a separate download (`ACE_NADI_production_GIFs.zip`). Each one is 860px wide, 16:9, loops, is color-graded to the brand look, has no text on it, and weighs 4–7MB.

| File | Shows | Suggested section |
|---|---|---|

| `03_sealing_feed.gif` | Pouches feeding into the sealer | Sealing |
| `04_heat_seal_closeup.gif` | Heat-seal rollers close-up, slow motion | Sealing ("신선함을 그대로") |

**How to use them:** put Korean headline and copy on the JPG slices above or below each GIF. In the Smart Store and cafe24 editors, GIFs are uploaded as separate images stacked between the JPG slices.

**Note:** workers' faces are visible in 05 and 07. Confirm staff consent before publishing.
